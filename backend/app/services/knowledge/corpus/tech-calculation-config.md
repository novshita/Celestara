title: Calculation settings and reproducibility
category: technical
version: 1
aliases: calculation configuration, config, settings, reproducible, ayanamsa setting, node type, dasha year length, house system setting
---
Every chart is produced under an explicit configuration: the ayanamsa, the house systems, the aspect orbs, whether outer planets are included, the node type (mean or true), the Dasha year length and the ephemeris source. The same birth data with the same configuration always gives the same result, and the configuration is returned with the chart so a result can be reproduced or explained later. Changing a setting changes the result, which is why it is shown and never hidden.
